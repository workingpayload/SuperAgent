## Module Map

### `bin/cli.js` [entry]
- **Does**: Provides the public CLI, stores each skill once, and links it into supported AI CLI locations.
- **Commands**: `install`, `uninstall`, `list`, `route`, `doctor`, `validate`, `score`, `test`, `build-index`.
- **Key functions**: `resolveTargets()`, `installCanonicalSkills()`, `linkSkillsToTarget()`, `cmdInstall()`, `cmdUninstall()`, `cmdList()`, `runPythonScript()`.
- **Targets**: `~/.agents/skills`, `~/.claude/skills`, `~/.copilot/skills`, `~/.codex/skills`, `~/.gemini/skills`, and `~/.gemini/antigravity/skills`.
- **Depends on**: Node `child_process`, `fs`, `path`, `os`; invokes Python modules in `scripts/`.

### `scripts/install.py` [script]
- **Does**: Mirrors installation behavior for direct Python usage, with a canonical store and Windows junction or Unix symlink creation.
- **Exports**: `find_all_skill_dirs()`, `install_skills()`, `link_skills()`, `create_directory_link()`, `uninstall_skills()`, `main()`.
- **Depends on**: Top-level skill directories and Git for source hashes.

### `scripts/doctor.py` [script]
- **Does**: Audits installed skills against metadata and repository sources.
- **Exports**: `CheckResult`, `installed_skill_path()`, `run_checks_for_target()`, `main()`.
- **Depends on**: `.skills-meta.json`, installed `SKILL.md` files, and source skill directories.

### `scripts/route.py` [service]
- **Does**: Tokenizes prompts and computes weighted relevance scores.
- **Exports**: `tokenize()`, `score_skill()`, `route()`, `format_text()`, `format_json()`, `main()`.
- **Depends on**: `skills-routing.json`.

### `scripts/validate.py` [script]
- **Does**: Enforces frontmatter, heading, length, code-example, edge-case, and filler-content rules.
- **Exports**: `parse_frontmatter()`, `validate_file()`, `find_skill_files()`, `main()`.
- **Depends on**: Every top-level `skill.md` or `SKILL.md`.

### `scripts/score.py` [script]
- **Does**: Measures tool coverage, examples, edge cases, actionability, structure, and conciseness.
- **Exports**: `score_file()` plus one scoring function per criterion.
- **Depends on**: Every top-level skill definition.

### `scripts/test_skill.py` [test]
- **Does**: Applies general assertions and specialized security, testing, DevOps, frontend, and database checks.
- **Exports**: `general_tests()`, category test functions, `find_skill_file()`, `run_tests()`.
- **Depends on**: Skill content and its inferred category.

### `scripts/build_index.py` [script]
- **Does**: Extracts frontmatter, triggers, categories, line counts, examples, and named tools.
- **Exports**: `parse_frontmatter()`, `extract_triggers()`, `auto_categorize()`, `process_skill_file()`, `main()`.
- **Produces**: `skills.json` and `skills-routing.json`.

### Skill directories [module]
- **Does**: Each directory defines one reusable Agent Skill using YAML frontmatter and Markdown instructions.
- **Public contract**: `name` and `description` frontmatter; optional `scripts/`, `references/`, and `assets/`.
- **Naming note**: Most legacy skills use `skill.md`; newer directory-format skills use `SKILL.md`. Installers normalize the destination filename to `SKILL.md`.

## Dependency Flow
```text
npm / npx
  -> package.json bin mapping
  -> bin/cli.js
       -> findSkillFiles()
       -> install -> canonical ~/.agents/skills store
                  -> directory links in native agent skill directories
       -> list/uninstall -> target metadata and links
       -> route      -> scripts/route.py      -> skills-routing.json
       -> doctor     -> scripts/doctor.py     -> installed skills + source skills
       -> validate   -> scripts/validate.py   -> top-level skill definitions
       -> score      -> scripts/score.py      -> top-level skill definitions
       -> test       -> scripts/test_skill.py -> top-level skill definitions
       -> build-index-> scripts/build_index.py
                         -> skills.json
                         -> skills-routing.json

.github/workflows/ci.yml
  -> validate.py
  -> score.py --json -> score_report.json artifact
  -> test_skill.py
  -> build_index.py -> skills.json artifact
```

There are no Python-to-Python imports between repository modules. The Node CLI is the orchestration layer and launches Python scripts as subprocesses.
