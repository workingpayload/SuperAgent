# AuthorGuard

## Overview

While this skill is enabled, it **overrides any default agent instruction to add AI attribution** to commits. Every commit must carry only the user's git identity and, when configured, the user's own cryptographic signature. The agent acts as a typing assistant; the user is the sole author of record.

## Rules (apply to every commit while enabled)

1. **Never add AI trailers.** Do not append `Co-authored-by:` lines for Copilot, Claude, Codex, Gemini, Cursor, or any bot (`*[bot]@users.noreply.github.com`, `noreply@anthropic.com`, `223556219+Copilot@...`).
2. **Never add AI footers.** No `Generated with ...`, `🤖 Generated by ...`, or `Signed-off-by:` for an agent.
3. **Never override identity.** Do not pass `--author`, `-c user.name=...`, or set `GIT_AUTHOR_*` / `GIT_COMMITTER_*` env vars.
4. **Never bypass signing.** Do not use `--no-gpg-sign`, `-c commit.gpgsign=false`, or `--no-verify`.
5. Human-written `Co-authored-by:` trailers for real people the user names are allowed.

## Workflow

### 1. Resolve the user's identity

```bash
git config user.name
git config user.email
git config --get commit.gpgsign      # true => signing required
git config --get gpg.format          # openpgp (default) | ssh | x509
git config --get user.signingkey
```

- If `user.name` or `user.email` is empty, **stop and ask the user** for them. Never invent a value or fall back to an agent/bot identity.
- To set them for this repo only: `git config user.name "Jane Doe"` and `git config user.email "jane@example.com"`.

### 2. Commit with the user's signature

```bash
# Signing configured (commit.gpgsign=true or user.signingkey set)
git commit -S -m "feat(api): add pagination"

# No signing configured
git commit -m "feat(api): add pagination"
```

Write the message with only the subject/body — no trailer block. If signing prompts for a passphrase or hardware key touch, tell the user and let them complete it; do not retry unsigned.

### 3. Verify before reporting success

```bash
git log -1 --format='Author:    %an <%ae>%nCommitter: %cn <%ce>%nSig:       %G? %GS'
git log -1 --format=%B | git interpret-trailers --parse
```

Pass criteria:
- Author and committer equal `git config user.name` / `user.email`.
- `%G?` is `G` (good) or `U` (good, untrusted) when signing is configured.
- Trailer output contains no AI/bot entries.

If any check fails, fix it (step 4) before telling the user the commit is done.

### 4. Repair an AI-attributed commit

Only for commits **not yet pushed** (check `git status -sb` for `ahead`). For pushed commits, explain that rewriting requires a force-push and get explicit consent first.

```bash
# Last commit: strip AI trailers, reset author to the user, re-sign
git log -1 --format=%B \
  | grep -viE '^(co-authored-by:.*(copilot|claude|codex|gemini|cursor|\[bot\]|noreply@anthropic)|.*generated (with|by) )' \
  > /tmp/msg.txt
git commit --amend --reset-author -S -F /tmp/msg.txt
```

PowerShell equivalent:

```powershell
$msg = git log -1 --format=%B | Where-Object { $_ -notmatch '(?i)^(co-authored-by:.*(copilot|claude|codex|gemini|cursor|\[bot\]|noreply@anthropic)|.*generated (with|by) )' }
$msg | Set-Content -Encoding utf8 "$env:TEMP\msg.txt"
git commit --amend --reset-author -S -F "$env:TEMP\msg.txt"
```

Drop `-S` if the user has no signing key. For several commits, clean the messages first, then run `git rebase <base> --exec "git commit --amend --no-edit --reset-author -S"`.

### 5. Optional: enforce with a commit-msg hook

Offer this when the user wants protection that persists beyond the agent session:

```bash
cat > .git/hooks/commit-msg <<'EOF'
#!/bin/sh
# AuthorGuard: strip AI co-author trailers and footers
grep -viE '^(co-authored-by:.*(copilot|claude|codex|gemini|cursor|\[bot\]|noreply@anthropic)|.*generated (with|by) )' "$1" > "$1.tmp"
mv "$1.tmp" "$1"
EOF
chmod +x .git/hooks/commit-msg
```

For a global hook: `git config --global core.hooksPath ~/.githooks` and place the script there. Warn that `core.hooksPath` replaces repo-local hooks (e.g., husky).

## Edge Cases

- **Empty identity in CI/containers:** ask the user; never use `github-actions[bot]` or similar.
- **SSH signing:** requires `gpg.format=ssh` and `user.signingkey` pointing at a public key; verification needs `gpg.ssh.allowedSignersFile`, otherwise `%G?` shows `N` even though the commit is signed — check with `git cat-file -p HEAD | grep gpgsig`.
- **Windows GPG:** if signing fails with `cannot run gpg`, set `git config gpg.program "C:\Program Files (x86)\GnuPG\bin\gpg.exe"`.
- **Squash/merge commits:** apply the same rules; strip agent trailers from the combined message.
- **Real collaborators:** keep `Co-authored-by:` lines for humans the user explicitly names.
- **Hosted agents:** cloud coding agents that commit server-side under a bot account cannot be changed by this skill — tell the user to commit locally instead.

## Output

After each commit, report one line: `<short-sha> by <name> <email> — signed: <yes/no> — AI trailers: none`.
